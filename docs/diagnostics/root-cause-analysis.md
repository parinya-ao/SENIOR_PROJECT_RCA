## First failing boundary in the current real startup

The first startup attempt stopped at SIB parsing before signature/fuse reads.
After that gate was corrected, the current run passed device identity and fuse
verification, then stopped at the first physical byte mismatch. The console
never acquired runtime monitors; `events.jsonl` contains one host status row,
`messages.jsonl` is empty, and no DATA/ACK/NACK/Echo event was observed.

The current blocker is therefore exact: both installed images differ from the
fresh build, and the verified fuse layout has no APPCODE span for a safe
application-only repair. The chat path did not flash or transmit.
