## Driver and IRQ audit

Installed RadioLib is 7.1.2. Real public-HAL tests confirm begin/carrier E4C000,
IRQ reads without clears, W1C flags, TX FIFO and mode, finishTransmit 833 us/standby,
RX Continuous, readData clearing IRQ even on CRC error, and unchanged modem/IQ configuration across TX/RX.
SX127x has no finishReceive method. Firmware polls actual IRQ registers, so DIO0 wiring is recorded but an ISR is not required. Repeated RX commands are rejected without rearming or clearing an event. RxDone is snapshotted before standby/readData; packet handling precedes deadline handling.

Configuration snapshot address order:
`42 01 06 07 08 09 4D 1D 1E 26 20 21 39 33 3B 11 40 41 0C 31 37 24 4B`.
RAW_CONFIG is standby, RAW_TX_PRE is immediately before startTransmit, RAW_TX_STATE follows startTransmit, RAW_RX_ACTIVE follows startReceive.
Observations contain flags, header/packet counters, mode, ModemStat, HopChannel and accumulated observed flags. Header observation is bounded to one event; at most two packet observations, using the existing sixteen-slot nonblocking logger. Overflow invalidates evidence. No periodic log stream or repeated initialization was introduced.

[Semtech SX1276 datasheet, pp.106–111](https://cdn.sparkfun.com/assets/7/7/3/2/2/SX1276_Datasheet.pdf): bit 3 defaults to one and selects access to band-specific test registers. RadioLib setMode writes bits 2:0 and setFrequency writes the carrier; neither changes bit 3. Thus 0x89/8B/8D are explained by retained reset state. Source evidence does not establish a defective RF-band selection. No bit change is justified yet.
RegInvertIQ is handled deliberately by RadioLib invertIQ(false): RX bit6 clear, TX bit0 set, IQ2=1D. Its source documents swapped TX polarity relative to datasheet wording (issue778). Actual reserved bits produce 27; the zero-reserved-bit fake HAL produces01. Do not override this library behavior speculatively.
Counters 14–17 describe receive observations; Semtech specifies reset in Sleep and counts since transition into RX. Samples are taken in the same RX window before cleanup; fake HAL does not prove silicon counter lifetime.
