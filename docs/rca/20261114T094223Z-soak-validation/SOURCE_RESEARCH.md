## Radio airtime policy

The runner implements the Semtech LoRa packet-duration equation and tests 44-byte DATA as 92,416 µs and 12-byte response as 41,216 µs at SF7/BW125/CR4/5, preamble 8, explicit header, CRC on. At five worst-case attempts, 60-second start intervals keep the modeled individual-transmitter airtime below the conservative 1% target. This arithmetic is not an authorization or measured EIRP determination.
